# Contact-Dermatitis-institute-Database-Full
This is a fully offline comprehensive database of common causes of Contact Dermatitis in products, Scraped from https://www.contactdermatitisinstitute.com/database.php


This database contains 427 allergens from the Contact Dermatitis Institute website.

Each allergen entry includes the following information:

* **Allergen Name:** The main name of the allergen.
* **Where Found:** A short description of where the allergen is commonly found or used.
* **Other Names:** A list of chemical or trade name variations for the allergen.
* **Product Categories:** A list of product types in which the allergen is typically used or encountered.
* **Clinician Note:** Extra notes for medical professionals (often blank).
* **URL:** A link to the allergen’s page on the Contact Dermatitis Institute website for more details.

All data is stored in a JSON array, where each allergen is an individual object containing these fields.
